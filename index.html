지금 만들어 보세요

기본 정보, 소개, 태그, 이력, 영상까지 — 입력한 내용이 곧장 고급스러운 명함으로 완성됩니다.

체크한 항목은 명함 화면에서 숨겨집니다 — 이름·전화번호는 항상 표시됩니다.

소개 및 태그

자기소개를 작성하고, 전문 분야를 태그로 표현하세요.

0 / 800자

+ 태그를 입력해 보세요 (예: UX, 브랜딩)

Enter 또는 [추가] 버튼으로 태그를 등록하고, 칩의 ✕로 삭제할 수 있습니다.

3

이력 · 영상 · 링크

경력 사항과 소개 영상, 외부 링크를 자유롭게 추가하세요.

4

데이터 관리 · 백업 & 기기 이관

JSON 백업 파일로 명함 전체를 내보내거나, 새 기기에서 그대로 불러올 수 있습니다.

📥 데이터 가져오기

JSON / CSV / .vcf 백업 파일을 선택하세요. (JSON은 덮어쓰기/합치기 선택 가능)

백업에 0장의 명함이 있습니다. 어떻게 가져올까요?

💡 기기 변경 시: 기존 기기에서 내보내기 → 새 기기에서 가져오기. 또는 로그인하면 자동 동기화됩니다.

입력 정보는 이 브라우저(LocalStorage)에만 저장되며, 서버 실행 시 npm start로 DB 연동 모드를 사용할 수 있습니다.
